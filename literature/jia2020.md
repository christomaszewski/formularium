# Jia et al. 2020: a recurrent graph network pretrained on an uncalibrated river model, fine-tuned on few labels (rivers)

Predicts stream temperature and flow in a river network with a recurrent graph network pretrained on PRMS-SNTemp output and fine-tuned on real labels, against the physics model alone and the same networks without pretraining. No record: a method with a measured result.

**Read this first.** Rivers, not plants; the real labels are the variables the simulator outputs. A preprint (the SIAM venue it later appeared in was not checked). The headline claim, 33 % and 14 % better than the physics model with 0.1 % of the labels (l. 31), is the authors'; the table values below are the paper's own and are used instead.

## What it holds

- **Simulator** (l. 371, 405): PRMS-SNTemp with default parameter values, not calibrated ("extremely time-consuming", l. 371); run for every date from 1980-10-01 to 2016-09-30 (13,149 dates, l. 338), for 42 river segments of the Delaware River Basin feeding the Delaware at Wilmington (l. 335). The number of synthetic samples is not printed (42 segments by 13,149 dates is 552,258 segment-days, arithmetic, not printed).
- **Real data** (l. 385, 402, 409): real labels in the first 24 years (1980-10-01 to 2004-09-30), reduced to 0.1 % and 2 % of them or all (100 %); five repeats with random subsets and initialisation. The absolute count of labels is not printed.
- **Validation design** (l. 385): new years, same network: test on the next 12 years (2004-10 to 2016-09). Not a held-out segment or basin.
- **Temperature, test RMSE in degC at 0.1 % / 2 % / 100 % of labels** (Table I, l. 384-387, 390): physics model alone 3.661 (not recalibrated for the subsets); recurrent net not pretrained (the real-only baseline) 3.234 / 1.908 / 1.546; the same net pretrained and fine-tuned 2.818 / 1.810 / 1.444 (gain 0.42, 0.10, 0.10 degC, arithmetic, not printed); real-only ANN 3.706 / 2.159 / 1.575; the full model (pretrained graph network with contrastive loss) 2.464 / 1.636 / 1.402.
- **Streamflow, test RMSE in m3/s at 0.1 % / 2 % / 100 %** (Table II, l. 399, 401-402, 404): physics model alone 6.834; real-only recurrent net 6.885 / 5.718 / 4.406; the same net pretrained 6.367 / 5.529 / 4.104 (gain 0.52, 0.19, 0.30 m3/s, arithmetic, not printed); pretrained graph network 5.824 / 4.708 / 4.106.
- **Why simulated data are cheap** (l. 405): the simulator needs only the drivers, so it can be run on every date.
- **Where the physics model wins** (l. 409, 411, 415): at low-flow segments the physics model matched the observations better than the ML models; in high-flow segments it had a large bias and slow response. The authors' reason: low-flow headwater segments are a minority and add little to the loss.

## Dependence

- Pretrained on PRMS-SNTemp (USGS) output, including its intermediate variables (streamflow, stream temperature, relative humidity, cloud cover, groundwater). The pretraining strategy comes from the lake work of the same group (`jia2021`, `read2019`); several authors are shared (a flag).

## Bearing (2026-10-27)

- **Same pattern as the lakes, in a network:** pretraining on an uncalibrated simulator helps most at 0.1 % of labels and the gain shrinks to 0.10 degC (temperature) at 100 %, with a real-only baseline in the same table. This is real-data evidence for the pretrain-then-fine-tune design that D45 and D60 would use, in a field with a good teacher.
- **A model fitted on the simulator's output is kin to it (D45):** the check here is on the variable the simulator outputs, and the physics model keeps its edge in low flows, a regime the pretraining did not cover well. For Agrarium, the lesson is to report where the student loses, not only its mean.
- **Not shown:** a plant, a disease, a held-out site, or a hidden simulator variable judged by real data.
