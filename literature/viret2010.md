# Viret et al. 2010: VitiMeteo downy mildew forecasting on agrometeo.ch

A light read (the deep-research B list).

## What it holds

- The VitiMeteo-Plasmopara downy mildew forecast in the Agrometeo platform, run from a network of about 150 Swiss weather stations (l. 33).
- Stations record leaf-wetness duration and rainfall as well as temperature and humidity (l. 36).
- The output tables run from 1 January (l. 51).
- Oospores count as mature when they germinate within 24 hours (l. 71).
- Validation against field observations is claimed with no numbers (l. 77); growers can lengthen spray intervals in dry years (l. 87).

## Dependence

- Describes the VitiMeteo-Plasmopara model, whose oospore rule (140 degree-days above 8 C from 1 January) the engine runs. The paper gives no equation and no degree-day sum, so it neither computes nor fits that rule. The only shared feature is the 1 January start of the output tables (l. 51). Shared authors are flags only: Viret, Bleyer, Kassemeyer and Siegfried are VitiMeteo's developers (l. 5-6, 40-46).

## Bearing (2026-10-10)

- Describes the VitiMeteo model that the engine partly runs, but gives no oospore equation, so it cannot settle the 140 degree-day rule; the station network and the 1 January start are the useful details.
