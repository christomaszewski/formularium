# Jakkala & Akella 2023: Bayesian sensor placement for pathogen source localisation in wastewater

A Bayesian-network and discrete-optimisation method for placing autosamplers in a wastewater network so that infected buildings can be localised, with concentration requirements (l. 12-35). No record.

## What it holds

- **Method:** Bayesian networks combined with discrete optimisation to find informative placements, handling multiple sources (l. 28-34).
- **Test:** simulation experiments (l. 35); the extract does not name the real-world network or give error figures in the first pages.
- **Setting:** COVID-19 wastewater surveillance; not agriculture.

## Dependence

- Builds on Bayesian networks, pathogen concentration models and wastewater network topology.

## Bearing (2026-10-18)

- **Strand s6 (methods):** an example of placement under a minimum-concentration constraint, which has a parallel in trap placement. A simulator could take the idea of an information-based placement score; the network setting is not a vineyard.
