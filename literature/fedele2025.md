# Fedele et al. 2025: oospore dose and primary infections

## What it holds

- **Observation window (section 2.5):** each plant observed from budburst "till the end of
  primary inoculum season", which "was estimated using the epidemiological weather-driven
  model previously proposed by Rossi et al. (2008b)". Leaves counted weekly (twice weekly
  after rain); infected leaves removed to prevent secondary infections.
- **Dose (section 3.4):** lesions per plant correlate more with germinating oospores than
  with total oospores (0.967 against 0.941). Linear on logs: for oospores, a = −5.386,
  b = 0.786, R²adj 0.910; for germinating oospores, a = −2.662, b = 0.753, R²adj 0.924.

## Dependence

- **Calibrated with Rossi et al. 2008's model,** which set when observations stopped: a
  substantive dependency (`calibrated_with: rossi2008.primary`), found by an adversarial
  review on 2026-10-08.
- Shares authors with Caffi 2013 (a flag only).

## Bearing (2026-10-08)

  Rossi's model, would still hold Rossi's model out of the engine.
