# EFSA 2020: guidelines for statistically sound, risk-based plant pest surveys

An EFSA technical report (supporting publication EN-1919).

## What it holds

- A guideline, not a study. No observations are fitted (l. 3229).
- Method sensitivity = sampling effectiveness x diagnostic sensitivity (l. 1251). 0.7 x 0.8 = 0.56 needs 533 samples; 0.85 x 0.95 = 0.81 needs 368, at CL 95%, DP 1%, N = 100,000 (l. 1254, 1268-1270).
- Confidence: CL = 1 - (1 - MeSe.DP)^N (l. 1278). With MeSe = 1, DP 5% needs 59 samples; at DP 1% those 59 give 45% (l. 1284-1292).
- Finite population: CL ~ 1 - (1 - n.MeSe / (N - 0.5(N.DP.MeSe - 1)))^(N.DP) (l. 3243-3246). MeSe 0.8, DP 1%: 373 samples for N = 1,000,000 (l. 1682); 370 at N = 15,000 (l. 1373).
- Delimiting survey, DP 0.1%, N = 200,000: 3,716 samples (l. 2066).
- Components: CL = 1 - prod(1 - CL_i); two components of 78% give 95% (l. 1333).
- 100 units at MeSe 80% reach DP 3.7% (l. 1079).
- Formulas are credited to Cannon (2002), a different paper from Cannon (2001), l. 3229. They match Cannon 2001 Eq. 4.6, 4.10, 4.11.
- Reference only: the same structure as the engine's Cannon term.
