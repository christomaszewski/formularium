# Armstrong & Wicks n.d.: CropWatch downy mildew modeling, McLaren Vale

A light read (the deep-research B list).

## What it holds

- McLaren Vale CropWatch, South Australia, set up in 2003 under CropWatch SA; the region is 34 km from Adelaide (l. 11-13).
- Three parts: an AWS network feeding AusVit (l. 21-23), vineyard monitoring, and a bulletin; an SMS alert for primary infection (l. 46-47).
- Growers use protectant sprays, sprays on forecasts, or eradicant sprays after primary infection (l. 59-66).
- The D-Model simulates primary and secondary events; AusVit is the only commercial software holding it (l. 68-71).
- Five changes since 2003 raised reliance on the model; one is a rise in warm wet days before fruit set (l. 84-102).
- Recent model predictions often did not match field observations; six open questions (l. 104-134).
